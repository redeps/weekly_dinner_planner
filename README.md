# Meal Planner

A small household app for storing recipes and generating a weekly dinner
plan and grocery list.

## Status

Foundation (Milestone 0). See `docs/ROADMAP.md` for what's built and what's
next.

## Documentation

Start here, in this order:

1. `docs/PRODUCT_SPEC.md` — what this app is and isn't (source of truth)
2. `docs/ROADMAP.md` — milestone plan
3. `docs/DATA_MODEL.md` — database schema
4. `docs/DECISIONS.md` — architecture decision log
5. `docs/AGENT_INSTRUCTIONS.md` — rules for any coding agent (including
   Claude Code) working on this repo
6. `docs/AGENT_PROMPTS.md` — ready-to-use prompts, one per milestone
7. `docs/SETUP.md` — full setup + day-to-day workflow

## Quick start

```bash
pip install -r requirements.txt
streamlit run app.py
```

```bash
pytest
```

Full instructions, including GitHub Codespaces setup, are in
`docs/SETUP.md`.
